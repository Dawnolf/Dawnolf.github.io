
###### 문제 설명

함수 solution은 정수 n을 매개변수로 입력받습니다. n의 각 자릿수를 큰것부터 작은 순으로 정렬한 새로운 정수를 리턴해주세요. 예를들어 n이 118372면 873211을 리턴하면 됩니다.

##### 제한 조건

- `n`은 1이상 8000000000 이하인 자연수입니다.

##### 입출력 예

|n|return|
|---|---|
|118372|873211|


## 풀이

```cpp
#include <bits/stdc++.h>
using namespace std;

long long solution(long long n) {
    long long answer = 0;
    
    string tmp = to_string(n);
    cout<<tmp<<endl;
    sort(tmp.begin(),tmp.end(),greater<int>());
    
    for(long long i=0; i<tmp.length(); i++){
        
        answer+= tmp[i] - '0';
        if(i==tmp.length()-1) return answer;
        answer*=10;
    }
    return answer;
}
```

회사 다닌다고 너무 문제 풀이 안했더니 간단한 방식으로 생각을 안하는게 문제점인 듯
## 더 간단한 풀이

```cpp
#include <bits/stdc++.h>
using namespace std;

long long solution(long long n) {
    long long answer = 0;
    
    string tmp = to_string(n);
    sort(tmp.begin(), tmp.end(), greater<char>());
    
    answer = stoll(tmp);
    return answer;
}

```

stoll  은 long long 때 쓰임
